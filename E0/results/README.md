# E0 结果

- [实验报告](实验报告.md)：模型图、单卡/双卡运行对照表与流程图、运行方式、指标定义、中文图表与逐图解读，以及三个种子的完整结果。
- `mnist/`、`fashionmnist/`、`cifar10/`：正式 GPU/NCCL 结果，每个目录六次运行，共18个末轮模型。
- `figs/`：图1为训练吞吐，图2为更新耗时、同步耗时与占比，图4为最终测试准确率，均为无置信区间的单卡/双卡并列柱状图；图3(a)、图3(b)、图3(c)为三个数据集的20轮曲线，保留逐轮置信区间，文件名前缀为 `F3a`、`F3b`、`F3c`。解释性文字以中文为主，技术名称和数据集名称保留通用英文写法。另有模型图 `model_architecture.png/svg` 和单卡/双卡流程图 `single_dual_training.png/svg`。
- `seed_results.csv`：合并后的18次逐种子结果。
- `seed_summary.csv`：各配置的均值、样本标准差、观测范围、标准误、95% t置信限和 `n=3`。
- `epoch_summary.csv`：每轮独立计算的三种子统计与95% t置信限。
- `environment.json`：运行环境及训练源码快照位置。
- `validation.json`：18次运行的记录检查和GPU独立复测结果。
- `records_validation.json`：仅检查原始记录时的独立输出。
- `tests.log`、`tests.xml`：E0的36项回归检查输出。

统计读取三个数据集目录中的18次完整运行，并通过`run_id`关联逐步记录、20轮验证、末轮测试和检查点。

新实验默认写入 `reproduce/`，核验和绘图可选独立结果目录。具体命令见 [复现说明](../README.md#训练)。
